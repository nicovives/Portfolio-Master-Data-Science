# 👨‍💻 Portfolio de Data Science & Machine Learning

¡Bienvenido a mi portfolio! Este repositorio compila los proyectos prácticos y de investigación desarrollados durante mi **Máster Universitario en Ciencia de Datos**. 

Mi enfoque se centra en extraer valor de datos complejos, construir modelos predictivos robustos y diseñar arquitecturas analíticas escalables para resolver problemas de negocio reales.

## 🛠️ Stack Tecnológico

**Lenguajes:** Python, R, SQL
**Machine Learning & Deep Learning:** Scikit-Learn, PyTorch, PyTorch Geometric (PyG), TensorFlow
**Data Engineering & Cloud:** AWS (IoT Core, S3), Microsoft Azure (Serverless, AI Vision), Mosquitto, Node-RED
**Análisis y Visualización:** Pandas, NumPy, Matplotlib, Seaborn, Chart.js
